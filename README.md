# 👗 Smart Wardrobe

**No backend. No database. No API keys. Just React.**

Everything runs in your browser using localStorage.

---

## 🚀 Run in 3 steps

### Step 1 — Install Node.js
Download from https://nodejs.org (choose the LTS version)

### Step 2 — Open the project in VS Code
File → Open Folder → select the `outfitai` folder

### Step 3 — Run these 2 commands in the VS Code terminal

```bash
npm install
npm start
```

The app opens automatically at **http://localhost:3000** ✅

---

## That's it. Nothing else needed.

- ✅ No MongoDB
- ✅ No Cloudinary
- ✅ No Python
- ✅ No .env files
- ✅ No API keys
- ✅ Data saved in your browser

---

## Features

- Register / Login (stored locally)
- Upload clothes with drag & drop
- AI color detection (runs in-browser via Canvas)
- Generate outfit combinations by occasion + weather
- AI scoring engine ranks the best combinations
- Save your favorite looks
- Filter & search wardrobe
- Edit / delete items
- Fully responsive

---

## How to use

1. Register a new account
2. Go to **Upload Clothes** and upload photos of your clothes
3. Go to **Generate Outfit**, pick an occasion and weather
4. Save looks you love to **Saved Looks**

> **Note:** Data is stored in your browser's localStorage. Clearing browser data will remove your wardrobe. Don't use private/incognito mode if you want data to persist.
